# Crisp ASR 0.4.16 Reliability Design

## 目标

0.4.16 是 0.5 内容创作版本之前的可靠性收口。它解决外接麦克风热插拔、录音前确认、静音误结束、实时转写异常退出丢失以及历史录音重复扫描问题，不扩展新的 AI 服务商，也不恢复 Obsidian Electron 无法稳定支持的电脑声音采集。

产品主场景是个人口述与内容创作，多人会议和访谈只保留兼容性，不在本版本加入说话人分离或双声道工作流。

## 用户体验

### 外接麦克风

- 插件加载后监听系统音频输入变化，Wireless Mic RX、USB 麦克风、蓝牙耳机和虚拟声卡接入或移除后，面板设备列表自动刷新。
- 自动刷新不弹权限窗口、不自动切换用户已选设备。
- 手动刷新会申请一次麦克风权限，以获取完整设备名称。
- 已选设备断开时，面板明确显示“已选麦克风当前不可用”；开始听写时允许回退系统默认，但必须提示，不能静默回退。
- 设备重新接入后保留原选择，不要求用户重新配置。

### 麦克风测试

- 麦克风控件旁增加“测试”按钮。
- 测试只读取所选麦克风并驱动现有音量条，不连接豆包、不保存音频、不产生计费。
- 测试最长 10 秒，也可以手动停止。
- 测试期间显示实际采集设备名称；开始实时听写、切换设备或卸载插件都会先安全停止测试。

### 静音保护

- 增加三种策略：仅提醒、自动结束、关闭。
- 默认策略为“仅提醒”，默认时长 60 秒；可选 30、60、120 秒。
- 同一段连续静音只提醒一次，重新检测到声音后才允许下一次提醒。
- “仅提醒”不停止转写；“自动结束”保留当前文字并正常收尾。

### 实时恢复草稿

- 实时听写开始后创建内部恢复状态；有新的确定分句时，最多每 10 秒持久化一次。
- 草稿保存开始时间、目标笔记路径、确定分句、当前预览和更新时间，不包含 API Key。
- 正常写入成功后清除草稿；写入失败或异常退出时保留。
- 下次启动发现有效草稿时，在 Crisp ASR 面板显示恢复卡片。用户可以写回原目标笔记、创建独立恢复笔记或丢弃。
- 恢复写入成功后才清除草稿，避免二次丢失；重复点击不会重复写入同一份草稿。

### 历史录音扫描

- 扫描时除队列和处理历史外，也读取 Crisp ASR 转写笔记的 `source_audio` 属性，避免已存在转写笔记的录音再次出现。
- 处理历史上限从 500 提升到 5000，兼顾长期使用与 `data.json` 体积。
- 失败任务仍可重新扫描，正在处理或已经完成的任务不会重复入队。

## 状态与模块边界

- `audio-input.ts`：设备枚举、热插拔订阅、设备可用性和实际输入信息。
- `microphone-test.ts`：临时测试会话生命周期，不依赖豆包客户端。
- `live-draft.ts`：恢复草稿规范化、节流决策和恢复内容生成。
- `settings.ts`：新增静音策略、时长和可选恢复草稿；旧数据自动获得安全默认值。
- `main.ts`：编排设备监听、测试会话、草稿持久化、恢复动作和扫描来源。
- `asr-view.ts`：显示设备警告、测试状态和恢复卡片。
- `settings-tab.ts`：暴露静音策略与时长，不增加面向普通用户的内部恢复路径配置。

持久化必须串行执行，避免任务队列、设置修改和草稿检查点同时写 `data.json` 时互相覆盖。每次排队时保存不可变快照，最后排队的完整状态成为磁盘最终状态。

## 错误处理

- 自动枚举失败只保留上一次设备列表，不打断正在进行的听写。
- 手动刷新或测试失败显示可操作的中文错误，区分权限拒绝、设备断开和系统不支持。
- 外接设备在测试或听写中断开，沿用当前安全收尾逻辑并保留草稿。
- 草稿保存失败不停止听写，但显示一次警告；正常结束时再次尝试保存最终草稿后才写正式笔记。
- 恢复目标笔记已删除时，自动提供独立恢复笔记，不创建无效链接。

## 兼容与隐私

- 最低 Obsidian 版本保持 1.11.4，桌面端限定不变。
- 不新增运行时依赖，不改变豆包和 AI Key 的 SecretStorage 存储方式。
- 麦克风测试音频只在内存中使用，不上传、不保存。
- ALL 与 YS 的 `data.json` 分别保留，不跨仓库同步。
- 分享 ZIP 只包含运行文件和公开说明，不包含 `data.json`、源码、测试、依赖、备份、授权码、API Key 或本地绝对路径。

## 验收标准

- 热插拔测试证明设备变化会自动触发无权限刷新，并在卸载时取消监听。
- Wireless Mic RX 作为普通 `audioinput` 完整显示，可被测试和实时听写选择。
- 静音策略三种分支均有自动测试，默认仅提醒 60 秒。
- 实时草稿在新分句后节流保存，重启后可恢复，正常成功后清除，写入失败时保留。
- 已有 `source_audio` 转写笔记对应的录音不会再次出现在扫描列表。
- `npm run check` 全绿；源码、ALL、YS 三处运行文件哈希一致。
- ALL 与 YS 依次重载后 `dev:errors` 为空，面板布局在透明窗口中无错位。
- 桌面生成 `Crisp-ASR-0.4.16-share.zip` 并通过内容脱敏检查。

## 发布边界

本轮只完成本地源码、ALL、YS 和桌面分享 ZIP。用户实际测试通过前，不创建 GitHub Release、不推送远端、不发布公开更新。
