# Crisp ASR 0.4.16 Reliability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a locally deployed Crisp ASR 0.4.16 that reliably handles external microphone changes, safe microphone testing, configurable silence protection, recoverable live drafts, and accurate historical audio scanning.

**Architecture:** Keep audio acquisition and view rendering intact while adding focused device-test and live-draft modules. The plugin coordinates these modules and serializes all `data.json` writes so queue state, settings, and recovery checkpoints cannot overwrite each other.

**Tech Stack:** TypeScript 6, Obsidian API 1.13, Web Audio, Vitest 4, esbuild, Node.js deployment scripts.

## Global Constraints

- Keep Obsidian minimum version at `1.11.4` and `isDesktopOnly: true`.
- Do not add runtime dependencies or restore computer-audio capture.
- Default silence policy is `warn` after `60` seconds.
- Microphone tests never call Doubao, save audio, or write transcript content.
- Preserve ALL and YS `data.json` independently during deployment.
- Do not push or publish to GitHub before user testing.
- The source directory has no Git metadata, so commit steps are intentionally omitted rather than initializing a repository without authorization.
